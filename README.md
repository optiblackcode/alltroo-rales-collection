# Alltroo Rally Collection

## 📖 Overview

The **Alltroo Rally Extractor** is a simple tool designed to **extract rally data** from the Alltroo website and use it in your **Customer.io** email campaigns. This tool helps marketers and customer engagement teams easily collect information about ongoing rallies and integrate it into automated emails sent to users, making email campaigns more dynamic and personalized.

### **What Does It Do?**
- The tool allows you to **extract key rally data** from Alltroo’s rallies page, including the **name**, **description**, **link**, and **image** of each rally.
- The data is automatically organized and can be downloaded in multiple formats such as **CSV**, **TSV**, **Excel**, **JSON**, and **Markdown**.
- This data can then be easily imported into **Customer.io**, where it can be used in email campaigns to **personalize** and **dynamically include** information about specific rallies, directly engaging customers with the latest offers.

## 🚀 Key Features

- **Auto-fetch Rally Data**: Extract rally data directly from Alltroo by providing the rallies page URL.
- **HTML Paste Option**: If you have an HTML source of a rally page, you can paste it into the tool to extract specific data.
- **Multiple Export Formats**: Data can be exported as **CSV**, **TSV**, **Excel**, **JSON**, or **Markdown**.
- **Customer.io Integration**: The extracted rally data can be easily imported into **Customer.io** for email marketing.

## 🧑‍💻 How to Use the Tool

### Step 1: Open the Tool
Simply open the tool and choose your method for extracting rally data:
- **Auto-fetch from Alltroo**: Just provide the URL of the **Alltroo Rally page** (`https://alltroo.com/rallies/`), and the tool will fetch and extract the data automatically.
- **Paste HTML**: If you have the HTML content of a specific rally page, simply paste it into the input box and click **Extract from HTML**.

### Step 2: Extract Rally Data
- After providing the URL or pasting the HTML, click the **Extract** button.
- The tool will gather the rally details such as:
  - **Rally Name**
  - **Description**
  - **Rally Link**
  - **Image URL**

### Step 3: Download Data
- Once the data is extracted, you can **download it** in the format you prefer (CSV, TSV, Excel, JSON, or Markdown).
- For example, you can download the data as a **CSV** file to import it into **Customer.io**.

### Step 4: Use Data in Customer.io
- **Customer.io** is a powerful marketing automation platform that allows you to send targeted emails to your users. After extracting rally data, you can use it in your email campaigns by importing the data into **Customer.io**.
- You can dynamically include information about specific rallies (like **rally name**, **description**, and **image**) in your emails, making your communication with customers more **personalized** and **engaging**.

## 📈 Why Use This Tool?

### For Marketing Teams:
